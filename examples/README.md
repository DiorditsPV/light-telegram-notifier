## Дополнительный функционал

В примерах используется расширенный интерфейс отправки сообщений:

- HTML-форматирование текста через `parse_mode="HTML"`.
- Отключение превью ссылок через `disable_web_page_preview=True`.
- Формирование именованной ссылки через `make_link(url, text)`.

### Примеры

- `send_named_link.py` — отправка сообщения с именованной ссылкой.
- `reply_chatid.py` — получение ChatID и отправка тестового сообщения.
